# Premier League Home Goals Dashboard

A Power BI dashboard analysing how many goals each Premier League team scored and conceded in home matches.

## Questions answered
- Which teams score the most goals at home?
- Which teams are strongest, and weakest, defensively at home?

## Key findings
- Man City scored the most home goals (about 45), while Burnley scored the fewest (about 18).
- There were 580 home goals across 380 matches, about 1.5 per match.
- Some teams show a large gap between goals scored and conceded at home. For example, Wolves scored about 19 and conceded about 34.

## Tools
- Power BI Desktop

## Data
Match results from football-data.co.uk (free public dataset).

## Limitations
This analysis covers home matches only. It does not include away form, final league positions or head-to-head results.
